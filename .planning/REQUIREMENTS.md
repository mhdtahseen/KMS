# Requirements: KMS Consultants Rebuild

**Defined:** 2026-04-28
**Core Value:** Project a high-end, bespoke aesthetic that instantly communicates trust, exclusivity, and professionalism to high-net-worth and skilled immigration clients in Qatar.

## v1 Requirements

### Foundation & UI (FND)

- [ ] **FND-01**: Next.js 14 App Router project setup with Tailwind CSS
- [ ] **FND-02**: Framer Motion configured for page transitions and micro-interactions
- [ ] **FND-03**: Custom Tailwind theme with #0D0D0D dark background and metallic gold accents
- [ ] **FND-04**: Typography configured (Playfair Display for headings, Inter for body)
- [ ] **FND-05**: Global Header with Navigation and EN/AR language switcher
- [ ] **FND-06**: Global Footer with contact info and legal links
- [ ] **FND-07**: Complete RTL (Right-to-Left) layout support for Arabic

### Home Page (HOM)

- [ ] **HOM-01**: Hero section with dynamic map graphic and "Making Dreams Come True" copy
- [ ] **HOM-02**: Statistics/trust indicators row (1,000+ Visas, 5+ Global Destinations, etc.)
- [ ] **HOM-03**: Specialized Immigration Pathways grid (hover effects on cards)
- [ ] **HOM-04**: Process Timeline (The KMS Journey) vertical/horizontal visualizer
- [ ] **HOM-05**: Global Destinations section with city photography
- [ ] **HOM-06**: Client Testimonials slider/grid
- [ ] **HOM-07**: Call-to-action "Your Journey Begins With A Conversation" section

### Service & Destination Pages (SRV)

- [ ] **SRV-01**: Skilled Immigration Service template page
- [ ] **SRV-02**: Service page: Strategic Talent Relocation section
- [ ] **SRV-03**: Service page: Eligibility Matrix checklist
- [ ] **SRV-04**: Service page: Elevate Your Professional Horizon CTA
- [ ] **SRV-05**: Canada Destination Guide template page
- [ ] **SRV-06**: Destination page: Why Canada section (stability, education, prosperity)
- [ ] **SRV-07**: Destination page: Available Visa Pathways grid
- [ ] **SRV-08**: Destination page: Residency Requirements checklist

### Booking & Conversion (BKG)

- [ ] **BKG-01**: Private Consultation Booking form UI
- [ ] **BKG-02**: Form fields: Name, Email, Phone, Intended Service, Destination, Message
- [ ] **BKG-03**: Form validation (required fields, email format)

## v2 Requirements

### Backend Integration (BND)

- **BND-01**: Form submission integrated with Nodemailer to send emails
- **BND-02**: CMS integration for easy content updates

## Out of Scope

| Feature | Reason |
|---------|--------|
| CMS Integration | Deferred to v2. Content will be static code/JSON for initial launch. |
| Database Storage | Not required for initial lead generation form (emails suffice). |
